# Changelog

## 2.0.0
- Consolidated the existing GlassUI 1.0.0 framework into the complete release.
- Added runtime theme and accent switching.
- Added Graphite, Liquid, FullGlass, and Solid material presets.
- Added badge, progress bar, search, keybind, range slider, color palette picker, accordion, code block, console, and stat card components.
- Added Glass Studio 6.0 showcase.
- Added installation guide, API reference, engineering notes, and test checklist.
